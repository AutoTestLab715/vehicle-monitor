## 执行命令速查

```powershell
pytest                          # 全量（44 常规 + 3 fault skip）
pytest -m smoke                 # 冒烟
pytest -m websocket             # WebSocket
pytest -m "not fault"           # CI 默认（排除故障注入）
pytest -m fault --run-fault-tests   # 故障注入（管理员）
run-allure.bat                  # 测试 + Allure 报告
```
